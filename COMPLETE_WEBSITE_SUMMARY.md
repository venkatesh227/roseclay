## 🚀 HOW TO USE

### **1. Include CSS Files:**
```html
<link rel="stylesheet" href="style.css">
<link rel="stylesheet" href="pages-styles.css">
```

### **2. Include JavaScript:**
```html
<script src="script.js"></script>
```

### **3. Test the Flow:**
1. Start at `index.html`
2. Click "Login" → Register new account
3. Browse products → Add to cart
4. View cart → Proceed to checkout
5. Complete checkout → View orders
6. Manage profile → Logout
